// featured project

HassenCo

Production e-commerce platform for a premium handmade leather goods brand

Designed and built end to end: a TypeScript monorepo (Turborepo) with a Fastify / Apollo / TypeGraphQL API, a Next.js 16 storefront, and a MongoDB / Prisma data layer. JWT authentication with role-based access control, anonymous-to-authenticated cart merging, GraphQL Codegen for end-to-end type safety, an admin dashboard with image upload, and a Vitest suite wired into GitHub Actions CI.

  • End-to-end type safety: Prisma → TypeGraphQL → GraphQL Codegen → typed React Apollo hooks
  • Session-based anonymous carts with server-side merge on login
  • API hardening: rate limiting, CORS, structured Pino logging with request IDs
  • Admin dashboard: product/category/order CRUD + JWT-protected image upload
  • ~2,000 lines of Vitest across seven service modules + GitHub Actions CI
